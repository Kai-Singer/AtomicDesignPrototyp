# Atomic Design Prototyp by Kai Singer
Prototyp eines modularen Verwaltungsportal auf Basis des Atomic-Design-Prinzips. Der Fokus liegt auf der Struktur der wiederverwendbaren Komponenten, um durch die verbesserte Wartbarkeit und Wiederverwendbarkeit die Erstellung neuer digitaler Verwaltungsleistungen zu verbessern. Das Projekt wurde im Rahmen einer Bachelorarbeit erstellt.
